JanAushadhi Sarthak

  • Flutter
  • Python
  • FastAPI
  • SQLite
  • Raspberry Pi
  • GitHub Actions

An end-to-end system that makes India's generic-medicine data actually usable — an automated pipeline that scrapes the official JanAushadhi portal, a self-hosted API serving it, and a Flutter app on top.

  • Built an automated data pipeline that authenticates with the official JanAushadhi portal, streams government PDFs in-memory and parses their tables using pdfplumber with coordinate-tracking strategies — eliminating manual downloads and producing clean datasets of 20,700+ store locations and 2,400+ generic medicines with drug codes and MRP.
  • Automated a weekly sync with GitHub Actions that rebuilds indexed SQLite databases and CSV snapshots, versions them in Git for week-over-week change tracking, and pushes a run report (row counts, status, duration) through a Telegram bot.
  • Designed and self-hosted the resulting FastAPI service on a Raspberry Pi, syncing the generated databases via a weekly cron and exposing medicine search (by drug code or generic name), Kendra lookup (by pincode, state, district or Kendra code) and a health endpoint — indexes tuned for sub-second queries on low-power hardware.
  • Developed the Flutter client on the API with flexible store discovery, colour-coded availability and pricing indicators, one-tap calling and Google Maps navigation, and a persistent cart that saves medicine lists as reusable drafts across sessions.
  • Shipped the app through a CI/CD workflow that auto-bumps the version and publishes split-per-ABI and universal signed APKs to GitHub Releases, with sanitized error handling that routes server-side failures to an in-app support page.
